# Vokal docs

This repository contains the Mintlify documentation site for Vokal.

## Development

Install the Mintlify CLI:

```bash
npm i -g mint
```

Preview locally from the repository root:

```bash
mint dev
```

Validate the site and check links before publishing:

```bash
mint validate
mint broken-links
```

## Publishing

The production site is connected to the `main` branch.
