## Sign in

Download Vokal from the [download page](https://vokal.team/download). These steps use the desktop app; mobile screens may differ.

Open Vokal and select **Sign in with browser**. Finish signing in, then return to the app. Select an existing organization or follow the steps to create one. If you received an invitation, use the account it was sent to.

An organization keeps your team's people, agents, conversations, and shared files together.

## Create an agent

1. Open **Agents** and select **New agent**.
2. Give the agent a name.
3. Choose **This computer** or **Vokal Cloud**.
4. Choose an AI engine and complete the setup shown.
5. Review any instructions and connected apps, then create the agent.

An agent on your computer needs that computer to stay awake and connected. A cloud agent runs independently of it. See [AI engines and locations](/agents/ai-engines) for setup details.

## Give it a clear request

Open the agent's chat and describe the result you want. Include the information it should use and how you want the answer presented. For example:

> Help me prepare a weekly project update. Ask me for the progress, blockers, and next steps, then turn my answers into a short draft for the team.

Read the result and ask for changes in the same conversation.

## Work with your team

Open **Chats** to start a channel or a direct message. Add an agent to a channel and mention it when you want its help.

Add files to [Drive](/workspace/drive) and review the drive's agent access before asking an agent to work with them. If a task needs another app, connect the account in [Connectors](/apps/connected-apps) and assign access to the agent.

Use [Tasks](/workspace/tasks) to track the work. Once a request works the way you want, use [Routines](/agents/routines) to repeat it on a schedule.
