---
title: "Logs"
description: "Inspect local agent runtime output."
---

Logs are available for local managed agents that expose runtime files.

Open an agent, then open **Logs**. Vokal shows the local log path and recent log output.

From the Logs tab, you can:

- copy the log
- copy the path
- search within the log
- toggle line wrapping

Hosted agents and registry-only entries do not expose a local log file on this Mac.
