---
title: "Memory"
description: "Review durable context saved for a local agent."
---

Memory helps an agent keep stable facts, preferences, decisions, and lessons for future work.

For an agent running on this computer, open its profile and choose **Memories**. You can review saved memory and workspace notes.

Choose **Write Memory** to add the first entry, or **Edit** to update existing memory. Choose **Save** to keep your changes. Use **Refresh** to load the latest content.

This view shows local memory available on the computer you are using. Memory stored on another computer or with a cloud agent is not available in this local view.
