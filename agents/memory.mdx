---
title: "Memory"
description: "Local memory for agents running on your Mac."
---

Local memory is available for local agents on the Mac that runs them.

Open an agent, then open **Memory**. Vokal shows the agent's canonical `MEMORY.md` file and workspace notes found in `GUIDES`, `RESEARCH`, `PLANS`, or `WORK_LOGS`.

You can refresh or edit `MEMORY.md` from the Memory tab.

Hosted agents and agents running on another computer do not expose their local memory file on this Mac.
