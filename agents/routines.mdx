---
title: "Routines"
description: "Schedule recurring agent work."
---

Routines are scheduled prompts for agents.

Open **Routines** to create, search, group, run, enable, disable, edit, or delete routines.

A routine has:

- an agent
- a name
- a prompt
- a target: **DM with you** or a channel
- timing: cron or interval

The Routines form includes presets for every minute, hourly, daily, weekdays, weekly, monthly, and custom cron.

For channel routines, the target channel must be available in the workspace. If the selected agent is not already a channel member, Vokal can add the agent before saving the routine.

The **Recent Runs** tab shows recent routine runs and their status.
