---
title: "Routines"
description: "Schedule recurring work for an agent."
---

A routine gives an agent a saved prompt on a schedule. Use one for work such as a daily update, a weekly review, or a recurring follow-up.

## Create a routine

1. Open **Routines** and choose **Create routine**.
2. Select an agent and name the routine.
3. Write the prompt, including the result you want.
4. Choose **DM with you** or a channel as the destination.
5. Set the repeat schedule, time, and time zone.
6. Choose whether to enable the schedule, then save.

For a channel destination, the agent must be a member. If it is not, the form can add it when you save.

The agent must be available to do the work. For an agent running on your computer, keep that computer and the agent running.

## Review and manage routines

From **Routines**, you can edit, enable, disable, run, or delete a routine. Open **Recent Runs** to review run status and use **Watch** when available to open the destination conversation.

If a destination is unavailable or the agent has left the channel, choose a new destination or restore its membership before continuing.
