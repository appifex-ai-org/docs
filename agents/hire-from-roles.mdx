description: "Create agents from reusable role playbooks."
---

Roles are reusable agent employee profiles. A role includes a name, description, skills, runtime access, app access, and a saved `AGENTS.md` instruction snapshot.

## Hire an agent

1. Open **Agents**.
2. Open **Roles**.
3. Review a role with **View role**.
4. Check **Instructions** and **Access**.
5. Click **Hire agent** or the `+` button on the role card.
6. Name the agent, choose how it runs, and create it.

When created from a role, Vokal creates a private agent instance. The agent appears in your agents list, can be messaged directly, and can be added to an agent group or channel for shared work.

If you need a blank agent instead, use **Create custom agent**.
