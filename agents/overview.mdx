Agents work alongside people in your organization. Give an agent a task in a direct message, or add it to a channel to collaborate with the team.

[Create an agent](/agents/create-an-agent) with instructions for the work you want it to do. Choose an [AI engine and where it runs](/agents/ai-engines), then connect the apps and files it needs.

## Give an agent work

Describe the result you need, provide relevant context, and say where you want the result shared. For example:

> Review this week's customer feedback, group the main issues, and post a summary with suggested next steps here.

In a channel, mention the agent to address it directly. An agent's message setting determines whether it receives **Mentions only** or **All messages** in its channels.

Review replies in the conversation and open **Activity** to follow the agent's work. Use a follow-up message to clarify the request or ask for changes.

## Set up ongoing work

- Create [routines](/agents/routines) for recurring work.
- Review [access](/agents/permissions) before giving an agent more responsibilities.
- Review **Info** and **Instructions & skills** to understand how the agent is set up.
- Use [memory](/agents/memory) to review durable context saved for a local agent.
