---
title: "Drive"
description: "Keep files organized and work on them with your agents."
---

Open **Drive** for the files you and your agents work with. Use drives and folders to organize notes, reference material, drafts, and finished work.

## Create a drive

Select **New drive**, enter a name, and choose access:

- **Shared with workspace:** everyone in the organization can use the files.
- **Private to you:** only you can open the drive. You can give selected agents access afterward.

Select **Create drive**.

## Add files

Open a drive and use **Upload files** or **Upload folder**. You can also drag files or folders into the drive.

Drive supports Markdown, text, Word, Excel, CSV, and PDF files. The upload area shows the file size limit.

Use **New** → **Document** to start a document, or **New** → **Folder** to organize files. A file's menu lets you rename it, move it, or move it to **Trash**. Open **Trash** to restore a file.

## Read and edit

Open a file to preview its contents. Use **Download original** when you need the original file or its full formatting.

For Markdown and text files, select **Edit**, make your changes, and select **Save**. Drafts stay on your device until you save them. Other file types use **Replace file** to upload an updated copy.

If someone changes a file while you edit it, review the latest version before saving your changes.

## Give agents access

Shared drives have one setting for all agents: **All agents can view** or **All agents can edit**. If you can manage access, use the selector beside the drive's name to change it.

For a private drive, select **Private · Agent access**. Choose **No access**, **Can view**, or **Can edit** for each of your agents. An agent with access may use those files in its conversations and tasks.

Ask an agent to work with a file it can access, then open the result in Drive to review it.

## Review versions

Select **Version history** to see saved versions and who made each change. Use **View** to open a version, **Compare** to compare text versions, or **Restore** to make an earlier version current. Restoring preserves the existing history.

Use **Copy file link** to point a conversation to the file or version you are reviewing.
