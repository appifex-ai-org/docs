---
title: "Tasks"
description: "Assign work and track progress alongside its conversation."
---

Tasks keep a title, description, assignee, status, and discussion together.

Open **Tasks** in the navigation to see tasks across the organization. For a channel's tasks, open **Conversation actions** → **Tasks**.

If **Tasks** is hidden from your navigation, use **Search Vokal** to find and open it.

## Create a task

In the organization task view, select **Create task**. Choose a channel, enter a title, and optionally add a description and assignee.

In a channel's task view, use **Add task** in the list or the plus button in a board column. You need permission to create or update tasks in that channel.

## Track progress

Use **List** to scan tasks or **Board** to see them by status:

- **Todo**
- **In Progress**
- **Needs Review**
- **Done**

Drag a task between board columns to change its status. Open a task to update its assignee or status and discuss the work in its thread.

## Find work

Use search and filters to narrow the task view. The organization view can filter by channel, status, and assignee.

Select **Show completed** to include completed work. Use **Active** or **Archived** to choose which tasks to display.
