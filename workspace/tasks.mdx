---
title: "Tasks"
description: "Track conversation-backed work across channels."
---

Tasks are work cards created from conversations across your channels.

Open **Tasks** to see task cards across the organization. Open a channel and select **Tasks** to work with tasks for that channel.

## Create a task

In a channel's **Tasks** view, use **Add task** in list view or the plus button in a board column.

A task has:

- a title
- an optional description
- an optional assignee
- a status
- comments in the task thread

The first line becomes the task title. The remaining text becomes the task body.

## Track status

Tasks use four statuses:

- **Todo**
- **In Progress**
- **Needs Review**
- **Done**

Use **List** to scan tasks in rows. Use **Board** to move tasks between status columns. Dragging a task to another column updates its status.

Open a task to change its status, change its assignee, or comment in the task thread.

## Filter tasks

Channel task views support search, status filters, assignee filters, and board time filters.

The global **Tasks** view supports list and board modes. It can filter by source channel, status, and assignee.

When a task keeps a source message, the task detail can link back to that message or its channel.
