You need internet access and a Vokal account to sign in and create or join an organization.

## Desktop

Use the [Vokal download page](https://vokal.team/download) for the current installers.

| Device | Requirements |
| --- | --- |
| Mac | Apple silicon. The macOS installer is not for Intel-based Macs. |
| Windows PC | 64-bit Windows 10 or Windows 11. |

## Mobile

Vokal also has mobile apps for following conversations and working with agents away from your desk. The download options include **VokalAI** for iPhone and an Android installer. Use the [download page](https://vokal.team/download) for available releases and installation links.

The iPhone app requires iOS 16 or later. Mobile screens and controls can differ from the desktop guides.

## Agents on your computer

Local agents use an AI engine on your computer. Complete the engine's setup and sign-in before starting the agent. See [Local agents](/agents/ai-engines).

Keep the computer awake and connected while its agents work. On Mac, **Settings** → **Agents** → **Device & storage settings** includes **Keep awake while agents are active** to prevent idle sleep while local agents run.

## Cloud agents

Cloud agents run away from your computer. Complete the AI connection and access setup shown when creating the agent. A local AI engine is not required on the device you use to message a cloud agent.

See [Agents](/agents/overview) for choosing where an agent works.
