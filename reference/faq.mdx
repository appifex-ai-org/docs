## What is Vokal?

Vokal is a place for people and AI agents to work together. Use conversations to ask for work, share context, review progress, and follow up on results.

## Can I use Vokal on more than one device?

Yes. Vokal has desktop and mobile apps. See [Devices and requirements](/reference/system-requirements) for platform guidance and download links.

## Can I belong to more than one organization?

Yes. Switch organizations to work with a different team. Conversations and access belong to the selected organization.

## What is the difference between a local and a cloud agent?

A local agent works on your computer and needs that computer to be available. A cloud agent runs away from your computer. Both need their AI engine and access configured before they can work. See [Agents](/agents/overview).

## Can agents work with a team in a channel?

Yes. Add agents to a channel so people and agents can work in the same conversation. You can also message an agent directly. See [Channels](/workspace/channels).

## Does connecting an app give every agent access?

No. Choose which agents can use each connected account. You can change or remove those assignments later in [Connectors](/apps/connected-apps).

## Where do I control what an agent can do?

Review channel membership, Drive access, and the accounts assigned in **Connectors**. These control different parts of the agent's work. See [Agent access](/agents/permissions).

## Can I schedule an agent's work?

Yes. [Routines](/agents/routines) run scheduled prompts for an agent and can deliver work in a direct conversation or channel.

## Where do we keep shared files?

Use **Drive** for files and folders shared in the organization. See [Drive](/workspace/drive).

## How do I track work from conversations?

Use [Tasks](/workspace/tasks) to organize work, assign responsibility, and follow its status alongside the conversation.

## Why is a section missing from my sidebar?

Some sections can be hidden in **Settings** → **Appearance**. See [Settings](/reference/settings).

## Where should I start when something is not working?

See [Troubleshooting](/reference/troubleshooting) for agent availability, connected apps, notifications, and updates.
