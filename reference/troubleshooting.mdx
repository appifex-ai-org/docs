## An agent is not responding

1. Check that you are in the intended organization and conversation.
2. Open the agent and check its status. Follow any setup or sign-in request shown.
3. For a local agent, make sure its computer is awake, online, and running Vokal.
4. Check whether the conversation is waiting for an approval or a connected account.
5. Review the agent's [health and logs](/agents/logs) for more information.

A cloud agent can need attention even while your own device is connected. Check the agent's setup before sending the same request again.

## An agent cannot use an app

Open **Connectors** and check the account's status and assigned agents. A successful account sign-in does not automatically grant an agent access.

If authorization has expired, select **Reconnect**. If the wrong account is assigned, change the assignment. Review the agent's permissions if it can reach an app but cannot perform the requested action.

See [Connectors](/apps/connected-apps) for the full flow.

## I am not receiving notifications

Check **Settings** → **Notifications** in Vokal, then check your device's notification permissions for Vokal. Enable the alerts you want and decide whether they should include message previews.

On mobile, follow any **Enable notifications** or **Retry** prompt shown in settings.

## I cannot find a sidebar section

Check **Settings** → **Appearance**. Optional sections such as **Drive**, **Tasks**, **Routines**, and **Connectors** can be hidden.

If you cannot find a particular conversation or item, check which organization is selected and whether you have access to it.

## Local agent setup is failing

Confirm that the selected AI engine has completed setup and sign-in. In desktop **Settings** → **Diagnostics**, use **Check again** to review local tool readiness.

See [Local agents](/agents/ai-engines) for setup guidance.

## I may be using an older version

Open desktop **Settings** → **Updates** and follow the available update steps. Use the [download page](https://vokal.team/download) if you need to install Vokal again.
